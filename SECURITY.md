# Security Policy

## Supported versions

Security fixes are applied to the latest released version.

## Reporting a vulnerability

Please report vulnerabilities through GitHub private vulnerability reporting on this repository:

https://github.com/GregDog/mcp-server-abnormal/security/advisories/new

Do not open a public issue for a security problem.

Include:

- a description of the issue
- steps to reproduce
- affected version or commit
- any logs with tokens redacted

Do not attach Abnormal API tokens or other secrets.

Maintainers should keep GitHub secret scanning and private vulnerability reporting enabled.
